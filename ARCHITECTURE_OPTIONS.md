# Opcje do dodania do Architecture & Design (zamiast Code Reviews)

## Propozycje twardych umiejętności technicznych:

### 1. **Repository Pattern**
- Kluczowy wzorzec w Clean Architecture
- Oddziela logikę biznesową od źródeł danych
- Bardzo powszechny w profesjonalnych projektach Android

### 2. **Reactive Programming (RxJava/RxKotlin)**
- Zaawansowana umiejętność techniczna
- Używana w wielu enterprise projektach
- Ważna dla asynchronicznych operacji i streamów danych

### 3. **Modularization**
- Ważne dla skalowania dużych aplikacji
- Multi-module architecture
- Dependency management między modułami

### 4. **SOLID Principles**
- Fundamenty dobrego designu
- Twarda umiejętność architektoniczna
- Ważne dla maintainability

### 5. **State Management**
- Zarządzanie stanem aplikacji
- Ważne w architekturze nowoczesnych aplikacji
- StateFlow, LiveData, itp.

### 6. **Navigation Component**
- Część Jetpack
- Ważne dla architektury nawigacji
- Deep linking, navigation graphs

---

## Moja rekomendacja:

**Repository Pattern** - najbardziej pasuje do sekcji Architecture & Design, jest to konkretny wzorzec architektoniczny używany w Clean Architecture, który pokazuje zaawansowaną wiedzę.

Alternatywnie **Reactive Programming** - jeśli chcesz pokazać bardziej zaawansowane umiejętności techniczne.
